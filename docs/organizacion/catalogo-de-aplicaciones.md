# Catálogo de Aplicaciones

**Rutas:** `/store/apps` · `/store/agents`

## Descripción

Repositorio de aplicaciones y agentes preconfigurados que la organización puede incorporar sin construirlos desde cero.

## Catálogo de aplicaciones

| Pestaña | Contenido |
|---|---|
| **Disponibles** | Aplicaciones instalables |
| **Instaladas** | Aplicaciones ya incorporadas |

### Tipos de aplicación

| Tipo | Función |
|---|---|
| **Extensión** | Añade funcionalidad a la plataforma |
| **Visor** | Presenta datos en un formato específico |
| **Filtro** | Procesa o filtra información |

Cada aplicación indica su número de instalaciones. Las acciones disponibles son **Instalar** y **Desinstalar**.

## Centro de Agentes

Catálogo de agentes disponibles, con búsqueda por agente, modelo o categoría. La ficha de cada agente muestra:

- Iniciadores de conversación
- Capacidades
- Modelo y temperatura
- Especialistas integrados
- Fecha de última actualización

Con acceso directo a iniciar conversación.

:::tip Antes de crear desde cero
Conviene revisar el catálogo antes de construir un agente complejo: es posible que ya exista uno equivalente.
:::
