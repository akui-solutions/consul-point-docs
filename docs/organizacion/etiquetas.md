# Etiquetas

<PageMeta route="/settings/tags">permiso sobre **Etiquetas**</PageMeta>

Las etiquetas son palabras compartidas por toda la organización para clasificar elementos y encontrarlos después. Se crean en **Configuración → Etiquetas**.

<Screenshot src="/img/configuracion/etiquetas.png" alt="Etiquetas en Configuración" caption="Configuración → Etiquetas" />

## Dónde se usan

| Elemento | Dónde se pone | Dónde se filtra |
|---|---|---|
| Personas y entidades de [Contactos](/modulos/contactos) | Campo **Etiquetas** de la ficha | Filtro **Etiqueta** de cada lista |
| [Habilidades](/control/estudio/habilidades) | Campo **Etiquetas** de la habilidad (hasta 20) | Búsqueda **Buscar por nombre o etiqueta** de la biblioteca |

Para ver y elegir etiquetas hace falta permiso de ver **Etiquetas**.

## Crear, editar y eliminar

- **Nueva etiqueta**: solo pide un **Nombre**, de 2 a 30 caracteres, sin repetir el de otra etiqueta.
- **Editar** cambia el nombre en todos los elementos que la tienen.
- **Eliminar** la quita de todo lo que la tenía asignada. No se puede deshacer.

Cada acción requiere el permiso correspondiente sobre **Etiquetas**. El plan fija el número máximo de etiquetas. Ver [Créditos y límites](/organizacion/creditos-y-limites#límites-del-plan).
