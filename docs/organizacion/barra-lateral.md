# Barra lateral

<PageMeta route="/settings/preferences">permiso sobre **Elementos fijados** y **Aplicaciones**</PageMeta>

En **Configuración → Barra lateral** se eligen las [aplicaciones integradas](/aplicaciones-integradas) que aparecen en la sección **Fijados** del menú lateral, para abrirlas con un clic.

<Screenshot src="/img/configuracion/barra-lateral.png" alt="Configuración de la barra lateral" caption="Configuración → Barra lateral" />

## Fijar una aplicación

1. Pulsar **Fijar elemento**.
2. Buscar la aplicación y pulsar el botón para fijarla.
3. Los administradores eligen además a quién se muestra:
   - **Solo para mí**: solo en su barra lateral (es la opción por defecto, y la única para quien no es administrador);
   - **Para todos**: en la barra lateral de toda la organización.

En la lista, las fijadas para todos llevan la etiqueta **Global**. Cada persona ve las aplicaciones fijadas para todos más las suyas, **hasta 10** en total.

## Ordenar y quitar

- Se reordenan **arrastrándolas**, aquí o en la propia barra lateral.
- **Quitar de la barra lateral** las retira. Las fijadas para todos solo las puede quitar un administrador.

El engranaje de la sección **Fijados** del menú lateral abre esta misma pantalla. Ver [Navegación](/introduccion/navegacion).
