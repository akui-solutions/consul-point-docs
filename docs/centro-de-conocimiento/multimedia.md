# Multimedia

Una carpeta de tipo **Multimedia** reúne vídeos y audios de YouTube. La plataforma obtiene la transcripción de cada uno y la divide en segmentos, que se pueden consultar y copiar.

Estas carpetas no admiten archivos: cada recurso es un enlace.

## Agregar un recurso

1. Crear una carpeta de tipo **Multimedia** (ver [Crear una carpeta](/centro-de-conocimiento/carpetas-y-archivos#crear-una-carpeta)).
2. Dentro de ella, pulsar **Subir audio o vídeo** (si también se pueden crear subcarpetas, está dentro del menú **Nuevo**).
3. Completar la ventana **Agregar recurso multimedia**:

   | Campo | Descripción |
   |---|---|
   | **Nombre** | Obligatorio, entre 2 y 100 caracteres |
   | **URL** | Obligatorio. Solo enlaces de YouTube (`youtube.com` o `youtu.be`). El vídeo debe ser público |
   | **Título original** | Se completa automáticamente desde YouTube |
   | **Tipo** | **Video** o **Audio** |
   | **Fuente** | **YouTube** |
   | **Descripción** | Opcional |

4. Pulsar **Guardar**.

## Transcripción y segmentos

Al abrir un recurso se muestran dos pestañas:

- **Transcripción**: el texto completo, con **Copiar transcripción**.
- **Segmentos**: la transcripción dividida en fragmentos.

**Procesar** obtiene la transcripción si aún no existe, y **Reprocesar** la vuelve a obtener. **Abrir original** abre el vídeo en YouTube.
