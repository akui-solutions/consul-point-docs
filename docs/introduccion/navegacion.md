# Navegación

La plataforma se organiza mediante un menú lateral persistente.

| Elemento del menú | Módulo | Función principal |
|---|---|---|
| Panel de control | Dashboard | Resumen de actividad y consumo |
| Conversaciones | Chat | Interacción con los agentes |
| Estudio | Studio | Creación y configuración de agentes |
| Centro de Conocimiento | Knowledge Hub | Gestión documental |
| Bandeja Inteligente | Smart Inbox | Correo con procesamiento automático |
| Espacios de trabajo | Workspaces | Segmentación organizativa |
| Catálogo de aplicaciones | Store | Aplicaciones instalables |
| Auditoría y Reportes | Consumption | Consumo, actividad y registros |
| Artículos y novedades | Resources | Contenido interno |
| Configuración | Settings | Administración de la organización |

:::note Visibilidad condicionada
El menú muestra únicamente los módulos habilitados para la organización y permitidos por el rol del usuario. Un menú incompleto no indica un error.
:::

## Idioma

La interfaz está disponible en **español e inglés**. El idioma se configura desde el perfil de usuario.
