# Glosario

| Término | Definición |
|---|---|
| **Agente** | Asistente de IA que conversa con las personas. Ver [Agentes](/control/estudio/agentes) |
| **Especialista** | Agente experto en un tema al que un agente consulta durante una conversación. Ver [Especialistas](/control/estudio/especialistas) |
| **Microagente** | Agente que hace una tarea concreta y devuelve datos con una estructura fija. Ver [Microagentes](/control/estudio/microagentes) |
| **Esquema de datos** | Estructura que define qué datos se extraen y con qué forma. Ver [Biblioteca de esquemas](/control/estudio/esquemas-de-datos) |
| **Capacidad** | Funcionalidad opcional activable por agente |
| **Instrucciones del sistema** | Texto que define el comportamiento permanente del agente |
| **Iniciador de conversación** | Frase sugerida para iniciar la interacción |
| **Temperatura** | Parámetro de determinismo frente a variabilidad (0–1) |
| **Modelo** | Motor de IA que ejecuta al agente |
| **Embedding** | Representación vectorial que permite la búsqueda semántica |
| **Token** | Unidad en que los modelos miden el texto que reciben y generan. Se descuenta en créditos |
| **Créditos** | Saldo con el que la organización paga el uso de IA |
| **Ventana de contexto** | Volumen de conversación que el agente retiene |
| **Fuentes del mensaje** | Información consultada para generar una respuesta |
| **Preparar para agentes** | Proceso que convierte un archivo en fragmentos buscables para que los agentes lo lean. Ver [Conocimiento de los agentes](/centro-de-conocimiento/conocimiento-de-los-agentes) |
| **Versión en texto** | Copia de un PDF convertida a texto, guardada junto al original |
| **Extracción inteligente** | Tipo de carpeta del Centro de Conocimiento que extrae datos estructurados de cada documento. Ver [Extracción inteligente](/centro-de-conocimiento/extraccion-inteligente) |
| **Integración** | Conexión configurada con un canal o sistema externo |
| **Supervisión humana** | Asunción del control de una conversación por una persona |
| **Espacio de trabajo** | Agrupación interna de usuarios, agentes y aplicaciones |
| **Aplicación integrada** | Aplicación con interfaz propia que se muestra dentro de ConsulPoint y trabaja con los datos de la organización. Puede ser una extensión, un visualizador o un filtro |
| **Mini App** | Nombre técnico de una aplicación integrada en la API y en el código |
| **Webhook** | Notificación automática a un sistema externo ante un evento |
| **Organización** | Entidad contratante; ámbito de aislamiento de los datos |
