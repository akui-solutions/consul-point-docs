# Multimedia

A **Multimedia** folder gathers YouTube videos and audio. The platform gets the transcript of each one and splits it into segments, which you can view and copy.

These folders do not accept files: each resource is a link.

## Add a resource {#agregar-un-recurso}

1. Create a **Multimedia** folder (see [Create a folder](/centro-de-conocimiento/carpetas-y-archivos#crear-una-carpeta)).
2. Inside it, click **Upload audio or video** (if you can also create subfolders, it is inside the **New** menu).
3. Fill in the **Add media resource** window:

   | Field | Description |
   |---|---|
   | **Name** | Required, between 2 and 100 characters |
   | **URL** | Required. Only YouTube links (`youtube.com` or `youtu.be`). The video must be public |
   | **Original title** | Filled in automatically from YouTube |
   | **Type** | **Video** or **Audio** |
   | **Source** | **YouTube** |
   | **Description** | Optional |

4. Click **Save**.

## Transcript and segments {#transcripción-y-segmentos}

When you open a resource, two tabs are shown:

- **Transcript**: the full text, with **Copy transcription**.
- **Segments**: the transcript split into chunks.

**Process** gets the transcript if it does not exist yet, and **Reprocess** gets it again. **Open original** opens the video on YouTube.
