# Conversations

<PageMeta route="/conversations">the relevant one on **Conversations**</PageMeta>

Conversations is where you talk to your organization's agents and where you handle the conversations that come in through WhatsApp, Telegram or other connected apps. It is also the place to test an agent before opening it to more people or connecting it to a channel.

This section requires no programming knowledge.

<Screenshot src="/img/en/conversaciones/conversaciones.png" alt="Conversations screen in ConsulPoint" caption="Conversations" />

## The screen {#la-pantalla}

| Area | Content |
|---|---|
| **Conversation list** (left) | Search box, agent filter, tabs by channel and the **New conversation** button |
| **Conversation** (center) | The messages, the message box and the header with the actions |
| **Side panel** (right, optional) | A second conversation or an integrated app |

### Tabs by channel {#pestañas-por-canal}

| Tab | Conversations |
|---|---|
| **All** | All of the below |
| **Internal** | Those started inside the platform |
| **WhatsApp** | Those that come in through a connected WhatsApp number |
| **Telegram** | Those that come in through a connected Telegram bot |
| **Other integrations** | Those that come in from external apps connected through the API |

Each conversation shows the agent or the contact, the date of the last message and, if any, an **unread** dot and the **human support** status (**Needs attention**, **You're handling this**, **Handled by…**).

## Which conversations each person sees {#qué-conversaciones-ve-cada-persona}

- **Their own**: the ones they started.
- **The ones shared with them**: see [Sharing and collaborating](/conversaciones/compartir-y-colaborar).
- **The ones from channels** they take part in: conversations from a WhatsApp or Telegram are seen by the owner and the team of that integration. See [Channels and human support](/conversaciones/canales-y-atencion-humana).

Nobody else, not even administrators, sees another person's conversations. Inside a [workspace](/modulos/espacios-de-trabajo) you only see that workspace's conversations.
