# Contact types

<PageMeta route="/settings/contacts/types">permission on **Contacts**</PageMeta>

Types classify the people and entities in [Contacts](/modulos/contactos): **Client**, **Supplier**, **Partner**… A contact can have several types, and you can filter by them in Contacts. You manage them in **Settings → Contact types**.

<Screenshot src="/img/en/configuracion/tipos-de-contacto.png" alt="Contact types in Settings" caption="Settings → Contact types" />

## Built-in and custom {#predefinidos-y-propios}

| Origin | Types |
|---|---|
| **Built-in** | **Client**, **Lead**, **Supplier**, **Partner** and **Collaborator**. They are always available and cannot be edited or deleted |
| **Custom** | The ones your organization creates |

## Create a type {#crear-un-tipo}

Click **New type** and fill in:

| Field | Content |
|---|---|
| **Name** | Required, up to 100 characters, and not the same as another type's |
| **Colour** | The color it is shown in |
| **Order** | Position in the list, lowest first |

## Delete a type {#eliminar-un-tipo}

You can use **Delete** even if the type is in use: the contacts and entities that had it lose it and keep their other types. If you later create a type with the same name, it is restored.
