# AI analysis

A [Mail Reader](/control/estudio/microagentes#lector-de-correo) assigned to a [rule](/bandeja-inteligente/reglas-de-correo) reads each email the rule captures and saves the result to the rule's folder. Analysis uses credits.

The analysis covers the sender, recipients, subject, date and body of the email. Attachments are not part of the analysis.

## What is saved {#qué-se-guarda}

Each Mail Reader has a **Result**, chosen when it is created:

| | Structured data | Summary |
|---|---|---|
| **What it generates** | The fields of a schema, always in the same format: summary, signals, entities, pending actions… | A text document with what matters in the email |
| **What it is for** | Reviewing and classifying emails, following up on orders or incidents, taking the data to tables or integrations | Reading or searching the content later, or giving it to an agent |

Either way, the result is saved to the rule's **Results folder**: one file per email, in monthly subfolders.

## Analyze an email {#analizar-un-correo}

1. Open the email and click **Show AI panel**.
2. Click **Analyze and save**.
3. The analysis takes a few seconds. You can keep browsing; the result appears in the panel, marked as **Saved**.

You can also start it from the sparkles button in the email list.

When an email cannot be analyzed, the panel tells you why and takes you to what needs changing:

| Message | What to do |
|---|---|
| **This email matches no active rule with a micro-agent.** | Create or adjust a rule, or turn on its AI analysis |
| **The rule that matches this email is disabled** | Enable it |
| **This email's rule has no results folder** | **Choose a folder in the rule** |
| **The rule's results folder no longer exists** | **Choose a folder in the rule** |
| **Another rule already saves the other kind of result in this folder** | **Go to the rule** and choose another reader or another folder |

## Analyze many emails at once {#analizar-muchos-correos-a-la-vez}

**Analyze pending** processes in a batch the emails of a rule that do not have an analysis yet. It is in the rule's **View details** (**Manual processing**) and in the list header when you filter by a rule with AI analysis.

- It analyzes up to 50 emails per run.
- By default, from the last 7 days, or from the rule's **Capture emails since** date.
- When it finishes, it shows how many were analyzed, how many were already saved, how many failed and how many are still pending. To continue, **Process again**.
- It stops if you run out of credits.

## The result {#el-resultado}

With a **Mail Reader**, the panel shows the result organized:

| Section | Content |
|---|---|
| **Summary** | The email in a few lines |
| **Signals** | **Urgency**, **Sentiment**, **Intention** and **Language** |
| **Sender** and **Recipients** | Who is writing and to whom |
| **Detected entities** | Names, companies, amounts, dates… |
| **Pending actions** | What the email asks to be done, with its priority |
| **Tags** | Suggested classification |

The sections depend on the reader's schema. The result is generated by AI and may contain errors.

With **Summary**, the panel shows the **Generated document**.

### Earlier summaries not yet saved {#resúmenes-anteriores-sin-guardar}

Some summaries generated before the folder became required show as **Not saved yet**. You can save them in two ways:

- **Save to the rule's folder**: saves it with the rule's other results. If the rule's reader is the one that wrote the summary, it does not use credits again.
- **Save to Knowledge Hub…**: saves it to the folder you choose.

## Analyze again {#volver-a-analizar}

**Analyze again** generates a new analysis, which becomes the email's result. It uses credits again and cannot be undone. If an analysis failed, **Retry and save** tries again.

## Credits {#créditos}

Each analysis uses the organization's credits, except with the organization's own models. Opening an email or viewing an existing analysis does not use credits. With no credits left, the panel says so, with a **View usage** link.

## Best practices {#buenas-prácticas}

:::tip Useful analyses
- Turn on analysis only in the rules whose emails need it: each analysis uses credits.
- For classification or follow-up, **Structured data**; to read or consult the content later, **Summary**. Results are kept organized by month and can be shared with an agent.
- Try a few emails one at a time before using **Analyze pending**.
:::
