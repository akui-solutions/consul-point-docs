# Common issues

## Access and accounts {#acceso-y-cuentas}

| Symptom | Cause and solution |
|---|---|
| The Smart Inbox icon does not appear | Your role has no permission on it. With the default roles, only administrators |
| **No email accounts connected** | Connect an account in **Settings → Connectors**. See [Connect an account](/bandeja-inteligente/conectar-una-cuenta) |
| An account that is connected does not appear | The account is **Private** and assigned to another user, or it is inactive |
| **Could not load emails** | The connection with the account failed. Click **Retry** and, if it persists, check the account in **Settings → Connectors** |
| An IMAP account cannot be connected | **Test connection** must return **Connection verified**. Check the server and port and, for Yahoo or iCloud, use an app password |
| The Smart Inbox does not appear inside a workspace | It is only available in the main organization |

## Rules {#reglas}

| Symptom | Cause and solution |
|---|---|
| An email does not appear when filtering by a rule | It does not meet all the criteria, or it is older than **Capture emails since** |
| The rule captures too many emails | Keywords match even when they are part of another word. Use senders or domains, or more specific words |
| A micro-agent does not appear when setting up the analysis | Only active ones of type **Mail Reader** and **Email to Markdown** are offered |
| **Summaries folder** cannot be selected | It is only available with a **Mail Reader** |
| The summaries folder gives an error | It must not be a smart extract folder, you must be able to write to it and the micro-agent must use a Google model |

## Attachments {#adjuntos}

| Symptom | Cause and solution |
|---|---|
| Attachments from new emails are not saved | They are not saved automatically. Use **Process attachments** on the rule |
| An attachment is missing | Its type is not in the rule's **File types**, or it is larger than 25 MB |
| **Failed to save the attachments** | Try again with **Process attachments**. If it persists, check that the folder exists and the plan's storage space |

## AI analysis {#análisis-con-ia}

| Symptom | Cause and solution |
|---|---|
| New emails have no analysis | Analysis is not automatic. Analyze them one by one or with **Analyze pending** |
| **Analyze pending** does not process all of them | It analyzes up to 50 per run. Click **Process again** |
| It stopped because of a lack of credits | Check usage and available credits with **View usage** |
| The analysis is shown but not saved | The rule has no **Summaries folder**, or the folder no longer exists |
| **Earlier analysis** next to the analysis | It was generated by another rule or an earlier attempt, and is not in this rule's folder. **Save with this rule** saves it there |
