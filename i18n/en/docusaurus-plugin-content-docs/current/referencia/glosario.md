# Glossary

The terms that appear on the platform and in this documentation, in alphabetical order. Each one links to the page that explains it.

## A {#a}

- **Agent**: AI assistant that talks to people, on the platform or on a connected channel. See [Agents](/control/estudio/agentes).
- **API key**: credential an external system uses to query the organization's agents. See [API keys](/organizacion/claves-de-api).
- **Articles & Updates**: module for publishing content for the organization, such as announcements or internal guides. See [Articles & Updates](/modulos/articulos-y-novedades).

## B {#b}

- **Built-in function**: platform feature that is turned on for each agent, such as **Web search**, **Attach files** or **Text to speech**. See [Built-in functions](/control/estudio/crear-un-agente#funciones-integradas).

## C {#c}

- **Capabilities**: agent tab that brings together its **built-in functions** and its **skills**. See [Agents](/control/estudio/agentes#capacidades).
- **Certified sources**: built-in function that lets the agent use verified information sources. It is turned on in each conversation. See [Built-in functions](/control/estudio/crear-un-agente#funciones-integradas).
- **Connector**: connection to an external tool that agents can use during a conversation. It is installed from the [Integrations catalog](/organizacion/catalogo-de-aplicaciones). It is not the same as an **integration**. See [Connectors](/organizacion/conectores).
- **Contact**: person or entity the organization deals with, for example someone who writes through WhatsApp or Telegram. Contacts are classified with **contact types** and **tags**. See [Contacts](/modulos/contactos).
- **Context window**: amount of conversation the model can take into account, measured in tokens. It depends on the model and cannot be configured. At 80% an indicator appears and at 90%, a warning. See [Context window](/conversaciones/conversar-con-un-agente#ventana-de-contexto).
- **Conversation**: exchange of messages with an agent, on the platform or on a channel. See [Conversations](/modulos/conversaciones).
- **Conversation starter**: suggested phrase to start talking to an agent. Each agent can have up to 5. See [Personalization](/control/estudio/crear-un-agente#personalización).
- **Credits**: balance the organization uses to pay for AI usage. They come in **credit vouchers**, which expire. If they run out, the agents stop answering. See [Credits and limits](/organizacion/creditos-y-limites).

## D {#d}

- **Data schema**: structure that defines which data is extracted from a document and in what shape. See [Schema library](/control/estudio/esquemas-de-datos).

## E {#e}

- **Email rule**: Smart Inbox rule that decides which emails are processed and how. See [Email rules](/bandeja-inteligente/reglas-de-correo).

## F {#f}

- **Folder**: unit used to organize and share knowledge. It can be **Standard**, **Multimedia** or **Smart Extract**. See [Folders and files](/centro-de-conocimiento/carpetas-y-archivos).

## I {#i}

- **Integrated app**: app with its own screen that is shown inside ConsulPoint and works with the organization's data. By origin, it is **Installed** (from the catalog) or **Custom**; by type, **Extension**, **Viewer** or **Filter**. See [Integrated apps](/aplicaciones-integradas).
- **Integration**: connection of a channel to the platform: WhatsApp, Telegram, an email account or an external app. See [Integrations and channels](/modulos/integraciones).
- **Integrations catalog**: place from which the organization installs ready-made apps and connectors. See [Integrations catalog](/organizacion/catalogo-de-aplicaciones).

## K {#k}

- **Knowledge Hub**: the organization's document repository, which the agents read from. See [Knowledge Hub](/modulos/centro-de-conocimiento).

## M {#m}

- **Message sources**: the information consulted to generate an answer: Knowledge Hub documents or web pages. You see it with **View sources**. See [Message sources](/conversaciones/conversar-con-un-agente#fuentes-del-mensaje).
- **Micro-agent**: agent that does one specific task, such as reading an invoice, and returns the data in a fixed structure. It does not hold conversations. See [Micro-agents](/control/estudio/microagentes).
- **Model**: AI engine each agent runs on, from Google, OpenAI or Anthropic. See [Model](/control/estudio/crear-un-agente#modelo).

## N {#n}

- **Needs attention**: mark on a channel conversation that needs a person. **Take this** assigns it to whoever takes it and the agent stops answering; **Mark as resolved** hands it back to the agent. See [Human support](/conversaciones/canales-y-atencion-humana#atención-humana).

## O {#o}

- **Organization**: the company or institution that subscribes to ConsulPoint. Its data is isolated from that of other organizations.

## P {#p}

- **Prepare for agents**: action that turns a file into fragments the agents can search and read. See [Agents' knowledge](/centro-de-conocimiento/conocimiento-de-los-agentes).

## R {#r}

- **Role**: set of permissions that defines what each person can do in each module. See [Roles](/organizacion/roles).

## S {#s}

- **Skill**: reusable procedure, with instructions and, if needed, files and scripts, that is assigned to agents and specialists. The agent uses it when it needs it. See [Skills](/control/estudio/habilidades).
- **Smart Extract**: folder type that extracts structured data from each document uploaded. See [Smart Extract](/centro-de-conocimiento/extraccion-inteligente).
- **Smart Inbox**: module that gathers the emails from connected accounts and brings their content into the Knowledge Hub. See [Smart Inbox](/modulos/bandeja-inteligente).
- **Specialist**: agent that is an expert in a topic, which an agent consults during a conversation. It does not talk to people. See [Specialists](/control/estudio/especialistas).
- **Studio**: module where agents, specialists, micro-agents and data schemas are created and configured. See [Studio](/modulos/estudio).
- **System instructions**: text that defines an agent's role, its limits and how it answers. It is what most affects the quality of its answers. See [System instructions](/control/estudio/crear-un-agente#comportamiento-instrucciones-del-sistema).

## T {#t}

- **Tag**: word shared across the whole organization to classify people, entities and skills. See [Tags](/organizacion/etiquetas).
- **Team**: group of users in the organization. It can be assigned, for example, to an integration so it handles its conversations. See [Teams](/organizacion/equipos).
- **Temperature**: agent setting between precise (0) and creative (1) answers. See [Model](/control/estudio/crear-un-agente#modelo).
- **Text version**: copy of a PDF converted to text and saved next to the original. If the folder is shared with agents, it is the version they read. See [Agents' knowledge](/centro-de-conocimiento/conocimiento-de-los-agentes).
- **Token**: unit models use to measure the text they receive and the text they generate. The tokens used are deducted as credits.

## W {#w}

- **Webhook**: automatic notice to an external system when an event happens on the platform. See [Webhooks](/control/webhooks).
- **WhatsApp template**: message approved by WhatsApp. It is the only way to write to a contact first on WhatsApp. See [Starting a conversation on WhatsApp or Telegram](/conversaciones/canales-y-atencion-humana#iniciar-una-conversación-por-whatsapp-o-telegram).
- **Workspace**: division of the organization with its own members, agents, apps, Knowledge Hub and articles. See [Workspaces](/modulos/espacios-de-trabajo).

## Y {#y}

- **Your own model**: AI model connected with the organization's own account, in **Settings → AI Providers**, if the plan includes it. Its answers do not use credits.
